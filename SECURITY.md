# Security Policy

## Supported Versions

Deep Researcher V2 is currently under active development.

Security updates are only guaranteed for the latest release available in the repository.

| Version              | Supported |
| -------------------- | --------- |
| Latest Release       | ✅         |
| Older Releases       | ❌         |
| Development Branches | ❌         |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, send details through one of the following channels:

* GitHub Security Advisories (preferred)
* Project maintainer email (if published)
* Private disclosure channel provided by the project

Please include:

* Description of the vulnerability
* Steps to reproduce
* Impact assessment
* Proof of concept (if available)
* Suggested mitigation (optional)

---

## Disclosure Process

1. Vulnerability report is received.
2. Report is reviewed and validated.
3. Fix is developed and tested.
4. Security release is published.
5. Public disclosure may occur after a fix becomes available.

We aim to acknowledge valid reports within 7 days.

---

## Security Considerations

Deep Researcher V2 interacts with external content sources, language models, local files, and web resources. Users should understand the following risks:

### Web Content

Research results are generated from third-party websites.

The project does not guarantee:

* Accuracy of external content
* Trustworthiness of sources
* Absence of malicious information on external websites

Always verify critical information independently.

### AI-Generated Content

Outputs generated by language models may:

* Contain inaccuracies
* Hallucinate facts
* Misinterpret sources
* Produce outdated information

AI-generated content should not be treated as authoritative without verification.

### Local File Processing

When processing local documents:

* Review documents before importing.
* Avoid importing sensitive files into untrusted environments.
* Use appropriate access controls on your system.

### Self-Hosted Deployments

For self-hosted installations:

* Protect API keys and secrets.
* Restrict database access.
* Enable HTTPS when exposed publicly.
* Keep dependencies updated.
* Apply operating system security updates regularly.

---

## Out of Scope

The following are generally not considered security vulnerabilities:

* AI hallucinations
* Incorrect research conclusions
* Low-quality model outputs
* Prompt injection attempts that do not result in privilege escalation
* Public information discovered through normal research workflows
* Denial of service caused by insufficient local hardware resources

---

## Responsible Usage

Deep Researcher V2 is intended as a research assistance platform.

Users remain responsible for:

* Verifying research findings
* Evaluating source credibility
* Complying with applicable laws and regulations
* Protecting sensitive data entered into the system

---

## Third-Party Services

Deep Researcher V2 may integrate with third-party services including:

* Search engines
* Language model providers
* Web crawling tools
* Document processing libraries

Users should review the privacy and security policies of those services before use.
